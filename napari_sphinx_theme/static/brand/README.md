# napari brand assets

The colours, code colours and icons that napari sites share, as plain files.
No Sphinx, pydata-sphinx-theme or build step is needed to use them.
napari-sphinx-theme uses them itself, so napari.org and every other site
draw from this one copy.

| File                | What it is                                                                                                                                                                   |
| ------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `napari-tokens.css` | CSS custom properties: the palette (`--napari-primary-blue`, ...) and light/dark roles (`--napari-color-text-base`, `--napari-navbar`, `--napari-footer`, ...). Hand-edited. |
| `pygments.css`      | Code colours for `.highlight` blocks: the napari style in light mode and dracula in dark, as on napari.org. Generated by `scripts/build_brand.py`; don't edit.               |
| `icons/*.svg`       | napari, napari hub, GitHub, PyPI, Bluesky, LinkedIn, image.sc and Zulip, filled with `currentColor` so they take the text colour.                                            |

Dark mode follows the reader's OS, unless the page picks a mode with
`<html data-theme="light|dark">` (pydata-sphinx-theme) or
`<html class="light|dark">` (mystmd).

## Using them from another site

Copy the files in at a pinned release rather than linking them live, so a
page's first load doesn't depend on a CDN. jsDelivr serves any file from a
commit. Use the release's full commit SHA, not its tag: a tag can be moved
to other content later, a commit can't.

    git ls-remote https://github.com/napari/napari-sphinx-theme refs/tags/<tag>
    https://cdn.jsdelivr.net/gh/napari/napari-sphinx-theme@<commit>/napari_sphinx_theme/static/brand/<file>

Review a copy's diff like code. Sites paste the icons into their pages, so
an SVG runs with the page's permissions. `tests/test_brand.py` rejects
icons that could run script or load anything, and CSS that loads anything.

The files also ship in the Python package. `pip install --no-deps
napari-sphinx-theme` brings them, and the `napari` Pygments style, without
Sphinx.
